# 시장 모니터링 사용법

## 화면 구성

왼쪽 메뉴는 실제 탭입니다. 선택한 탭의 내용만 표시하며 키보드 방향키·Home·End로도 전환할 수 있습니다.

| 탭 | 표시 항목 |
| --- | --- |
| 시장 개요 | S&P 500·Nasdaq 100·Dow Jones·Russell 2000과 VIX·미국 10년물 금리·USD/KRW |
| 관찰 종목 | 미국 시가총액 상위 20·50·100·200개 선택, 지수·섹터 ETF, 검색·추세 필터·정렬·상세 차트 |
| 데이터 상태 | 수집 성공·실패, 오래된 봉 수, 데이터 갱신 방법 |

대형주 범위는 주식에만 적용합니다. 지수 ETF 4개, 미국 섹터 ETF 11개와 시장지수·지표 7개는 별도로 유지합니다.
상위 200개 선택 시 대형주 200개, 지수 ETF 4개, 섹터 ETF 11개, 지수·지표 7개로 총 222개를 다룹니다.
대형주 20개를 수집하는 수동·정기 실행은 총 42개입니다.
표시 범위를 바꿔도 네트워크에서 새 시세를 가져오지는 않습니다.
보고서에 수집된 범위보다 큰 선택지는 비활성화합니다.
선택 범위는 가능하면 해당 브라우저에 저장하며, 저장을 사용할 수 없어도 선택 기능은 동작합니다.

## 종목 선정과 순위 갱신

출처: [Stock Analysis의 기업 시가총액 목록](https://stockanalysis.com/list/largest-us-companies/?count=500)

출처의 목록에서 다음 조건을 적용합니다.

- country가 United States이고 subtype이 stock인 primary listing
- OTC 등 경로형 티커 제외
- 같은 회사명과 같은 티커 중복 제거, 대표 티커 하나 사용
- 기업 시가총액 내림차순으로 상위 200개 선정

외국 기업의 미국 상장 주식이 원본에 포함될 수 있어 국가 필터를 별도로 적용합니다.
기업의 국가와 시가총액은 출처의 분류를 따르며, 최초 확인한 500개 중 조건에 맞는 기업을 선정합니다.
기준일·출처·기업별 시가총액과 순위를 config/monitor.json에 저장합니다.
출처 형식이 변경되거나 적격 기업이 200개 미만이면 오류를 반환하고 기존 설정 파일을 유지합니다.
고정 스냅샷이므로 아래 명령으로 목록을 갱신한 뒤 수집하세요. 정기 실행은 설정하지 않았습니다.

```sh
node scripts/update-universe.mjs
node scripts/monitor.mjs
```

## 실행과 결과 파일

Node.js 22 이상에서 외부 패키지 설치나 API 키 없이 실행합니다.

```sh
# 기본값: 설정된 최대 200개
node scripts/monitor.mjs

# 수집할 대형주 수 지정: 20, 50, 100, 200
node scripts/monitor.mjs --limit 50

# 이미 수집한 JSON만 HTML로 만들기
node scripts/render-dashboard.mjs
```

수집은 최대 4개 요청을 동시에 실행합니다. 종목 하나의 실패가 다른 종목의 수집을 중단시키지 않습니다.

- dashboard.html: 데이터를 포함한 단일 HTML 파일
- reports/latest.md: 최근 실행의 Markdown 보고서
- reports/latest.json: 최신 계산 결과·최대 90개 일봉 이력·단위·출처·오류 정보
- reports/<UTC 실행시각>.md 또는 .json: 실행별 기록

수집 실패가 있으면 해당 항목을 미확인으로 표시하고 종료코드 1을 반환합니다.
모든 항목이 수집되면 종료코드 0입니다. 실패한 가격을 과거 성공 값으로 채우지 않습니다.

## HTML 사용

dashboard.html을 내려받아 브라우저로 열면 됩니다. 별도 서버·설치·로그인이 필요하지 않습니다.
GitHub 파일 화면은 소스 보기이므로 Download raw file로 내려받으세요.

- 종목 선택: 최대 90개 일봉 가격 차트, 이동평균과 기준 시각 확인
- 종목 CSV 저장: 현재 범위와 검색·필터를 적용한 결과 저장
- 데이터 불러오기: 보고서 JSON을 외부 전송 없이 브라우저에서 처리
- 최신 데이터 갱신: 수집 스크립트 재실행 후 HTML을 다시 열거나 새 JSON 불러오기

페이지 새로고침은 새 시세를 수집하지 않습니다.
이전 20개 보고서도 불러올 수 있으며, 가격 이력이 없으면 차트에 이력 없음 안내를 표시합니다.

## 계산 기준

| 항목 | 정의 |
| --- | --- |
| 최신 값 | Yahoo 일봉 Close의 마지막 유효 값 |
| 일간·5일·20일 변화율 | 마지막 값 / 해당 관측치 수 이전 값 - 1 |
| 20·50·200일 이동평균 | 최근 유효 일봉 Close의 단순평균 |
| 거래량 배수 | 최신 거래량 / 직전 20개 봉 평균 거래량 (주식·ETF) |
| 금리 일간 변화 | 수익률(% 단위)의 차이 × 100, bp 표시 |
| VIX 일간 변화 | 지수의 절대 차이, pt 표시 |

필요한 이력이 없거나 거래량 평균이 0이면 미확인입니다.
가격은 API의 Close를 사용하며 Adj Close를 별도로 적용하지 않습니다.
배당 재투자 총수익률이 아니며 기업행동 전후 자료는 별도 확인이 필요합니다.

일봉은 장중에 갱신될 수 있어 확정 종가라는 보장은 없습니다.
봉·시세 시각은 원본 JSON에 UTC, 상세 화면과 수집 시각은 KST로 표시합니다.
항목마다 거래 시간과 휴일이 다르므로 동일 시점의 가격으로 해석하지 않습니다.
화면을 보는 시점에 마지막 봉이 4일 넘게 오래되면 확인 표시를 합니다.
이는 달력 일수 기준이며 거래소 달력에 따른 정밀한 휴일 판정은 아닙니다.
시장지표의 변화율은 주식 수익률로 해석하지 않습니다.

## 검증과 출처

- 가격: [Yahoo Finance](https://finance.yahoo.com/)의 공개 chart API
- API 예시: https://query1.finance.yahoo.com/v8/finance/chart/%5EGSPC?range=2y&interval=1d
- [Yahoo 이용약관](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html)
- 비공식 API이므로 응답 형식 변경·지연·요청 제한 가능
- 2026-11-16에 211개 항목을 모두 수집했습니다.
- 단위 검증: 20·50·100·200 범위, 범위 초과·중복 티커 거부, 미국 기업 필터, OTC 제외, 회사 중복 제거
- 브라우저 검증: 탭별 단독 표시, 20·50·100·200행 전환, 검색, 키보드 탭 전환, 211개 JSON 불러오기 및 모바일 배치

보유 포트폴리오 연동·자동 매매·정기 실행은 현재 구현 범위에 포함하지 않습니다.

## 미국 섹터별 대표 ETF

미국 S&P 500의 GICS 11개 섹터를 관찰하기 위해 Select Sector SPDR ETF를 사용합니다.
[운용사 공식 목록](https://www.ssga.com/us/en/individual/capabilities/equities/sector-investing/select-sector-etfs)을 2026-11-16 확인했습니다.

| 섹터 | ETF |
| --- | --- |
| 커뮤니케이션 | XLC |
| 경기소비재 | XLY |
| 필수소비재 | XLP |
| 에너지 | XLE |
| 금융 | XLF |
| 헬스케어 | XLV |
| 산업재 | XLI |
| 소재 | XLB |
| 부동산 | XLRE |
| 정보기술 | XLK |
| 유틸리티 | XLU |

기존 SPY·QQQ·DIA·IWM은 유지합니다. ETF를 추가한 것이 보유 비중이나 매수 결정을 의미하지는 않습니다.
섹터 ETF에도 변화율·이동평균·거래량 배수를 계산하고, 최근 90개 일봉 차트를 표시합니다.
시장 개요에는 11개 섹터의 가격·전일 대비를, 관찰 종목에는 별도의 ‘섹터 ETF’ 탭을 제공합니다.
Telegram 캡션과 ZIP 안 briefing.txt에도 섹터별 전일 대비를 포함합니다.
추가 검증: 222개 전체 수집 성공, 섹터 탭 11개 표시·검색·차트·모바일 배치 확인, 관련 테스트 8개 통과.
