# 시장 모니터링 사용법

## 현재 범위

- 지수: S&P 500, Nasdaq 100, Dow Jones, Russell 2000
- 시장지표: VIX, 미국 10년물 국채수익률, USD/KRW
- 지수 ETF 관찰용: SPY, QQQ, DIA, IWM (투자 비중이나 매수 대상 확정 아님)
- 미국 대형주: 시가총액 기준 상위 20개 기업의 대표 티커

대형주 목록은 [Stock Analysis](https://stockanalysis.com/list/largest-us-companies/)에서
2026-11-16 확인한 순위를 고정한 초기 목록입니다. Alphabet 등 동일 회사의 여러 주식
클래스는 대표 티커 하나만 사용합니다. 순위를 매번 자동 갱신하지는 않습니다.
변경 시 config/monitor.json의 목록·기준일·출처를 함께 갱신합니다.

## 실행

Node.js 22 이상에서 외부 패키지 설치나 API 키 없이 실행합니다.

```sh
node scripts/monitor.mjs
```

실행할 때 Yahoo Finance chart API에서 2년치 일봉을 가져와 보고서를 생성합니다.

- reports/latest.md: 최근 실행 보고서
- reports/<UTC 실행시각>.md: 실행별 보고서
- reports/<UTC 실행시각>.json: 계산 결과·단위·출처·오류 정보
- 최초 실행 기록: [초기 보고서](../reports/2026-11-16-initial.md)

수집 실패 시 해당 항목을 미확인으로 표시하고 종료코드 1을 반환합니다.
과거 성공 값을 현재 값처럼 채우지 않습니다. 모든 항목이 수집되면 종료코드 0입니다.
수동 실행 방식이며 정기 실행·알림·자동 매매는 설정하지 않았습니다.

## 계산 기준

| 항목 | 정의 |
| --- | --- |
| 최신 값 | Yahoo 일봉 Close의 마지막 유효 값 |
| 일간·5일·20일 변화율 | 마지막 값 / 해당 관측치 수 이전 값 - 1 |
| 20·50·200일 이동평균 | 최근 유효 일봉 Close의 단순평균 |
| 거래량 배수 | 최신 거래량 / 직전 20개 봉 평균 거래량 (주식·ETF만 표시) |
| 금리 일간 변화 | 수익률(% 단위)의 차이 × 100, bp로 표시 |
| VIX 일간 변화 | 지수의 절대 차이, pt로 표시 |

필요한 이력이 없거나 거래량 평균이 0이면 해당 계산은 미확인입니다.
가격은 API의 Close를 사용하며 Adj Close를 별도로 적용하지 않습니다.
배당 재투자 총수익률이 아니며 기업행동 전후 자료는 별도 확인이 필요합니다.

일봉은 장중에 갱신될 수 있어 마지막 봉이 확정 종가라는 보장은 없습니다.
봉 시각과 시세 시각을 각각 UTC로, 수집 시각은 KST로 표시합니다.
행마다 거래 시간과 휴일이 다르므로 동일 시점의 가격으로 해석하지 않습니다.
마지막 봉이 4일 넘게 오래되면 확인 표시를 하지만 거래소 달력을 사용하는 정밀 판정은 아닙니다.
시장지표의 이동평균과 변화율은 참고 수치이며 주식 수익률로 해석하지 않습니다.

## 출처와 검증

- 가격: [Yahoo Finance](https://finance.yahoo.com/), 공개 chart API 사용
- API 예시: https://query1.finance.yahoo.com/v8/finance/chart/%5EGSPC?range=2y&interval=1d
- [Yahoo 이용약관](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html)
- 비공식 API이므로 응답 형식 변경·지연·요청 제한이 발생할 수 있습니다.
- 2026-11-16 첫 실행에서 31개 항목(대형주 20개 포함) 수집 성공.
- 합성 가격·거래량으로 이동평균, 5일 변화율, 거래량 배수, 부족한 이력 처리를 검증했습니다.

보유 자산, 목표 비중, RSI·진입/청산 규칙과 자동 순위 갱신은 다음 단계에서 다룹니다.

## HTML 대시보드

저장소 루트의 `dashboard.html`을 내려받아 브라우저로 열면 됩니다.
별도 설치·서버·로그인이 필요하지 않으며 데이터와 차트를 파일에 포함합니다.
GitHub의 HTML 파일 화면은 소스 보기이므로 Download raw file로 내려받아 여세요.

- 지수 4개와 금리·VIX·환율 요약
- 대형주·지수 ETF·전체 탭, 검색, 추세 필터 및 열 정렬
- 종목 선택 시 최근 최대 90개 일봉 차트, 이동평균과 기준 시각 확인
- 현재 필터 결과 CSV 저장
- 새 보고서 JSON을 브라우저에서 불러오기 (외부 전송 없이 로컬 처리)

`node scripts/monitor.mjs`가 시세를 수집하고 JSON·Markdown·HTML을 함께 갱신합니다.
이미 수집한 JSON만 HTML로 만들려면 `node scripts/render-dashboard.mjs`를 실행합니다.
입력 기본값은 `reports/latest.json`이며 다른 JSON은 저장소 루트 기준 경로를 인수로 넘깁니다.

현재 HTML은 수집 시점의 스냅샷입니다. 페이지 새로고침은 새 시세를 수집하지 않습니다.
보고서 JSON에 과거 가격 이력이 없으면 차트 대신 이력 없음 안내를 표시합니다.
4일 초과 데이터 표시는 달력 일수 기준이며 거래소 휴일을 정밀 반영하지 않습니다.

화면 템플릿은 `templates/dashboard.html`, 생성 로직은 `scripts/render-dashboard.mjs`에 있습니다.
브라우저에서 검색·추세 필터·정렬·ETF 탭·상세 차트·CSV 저장·JSON 불러오기를 확인했고,
390px 모바일 배치에서 페이지 전체 가로 넘침이 없는 것을 확인했습니다.
