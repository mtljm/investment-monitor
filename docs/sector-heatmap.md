# 섹터 히트맵

- 면적은 S&P 500 지수의 11개 GICS 섹터 비중입니다. State Street의 **Index Sector Breakdown**을 사용하며 SPY 펀드 비중과 구분합니다.
- 비중·기준일·출처는 `config/sector-weights.json` 한 곳에서 관리합니다. 수동 갱신 시 이 파일만 수정하면 화면과 설명에 함께 적용됩니다. 시세 재수집은 하지 않습니다.
- 빌드 시 11개 섹터 누락·중복, 비중 합계, 유효 기준일·출처를 검사합니다. 반올림 오차는 면적 계산에서 정규화합니다. 기준일이 45일 넘게 지나면 화면에 갱신 확인 문구를 표시합니다.
- 색상은 기존 Select Sector SPDR ETF 일간 등락률입니다. 상승 빨강·하락 파랑, 절댓값 3%에서 농도를 제한합니다. 지수 섹터 수익률과 차이가 있습니다.
- 실패·오래된 봉·등락률 누락은 회색이며 구성비 면적은 유지합니다. 클릭·키보드로 공통 상세 창을 엽니다.
- 추가 API·서비스·인증정보·일정 변경은 없습니다.
