# 13F 기관 포트폴리오

- Berkshire Hathaway, Pershing Square Inc., Duquesne Family Office, Appaloosa LP를 참고합니다. 기관 합산 공시이며 개인 계좌·현재 보유를 뜻하지 않습니다.
- SEC 직접 수집의 접근 제한 때문에 공개 13f.info 목록·JSON을 사용합니다. 화면에 재가공 제공처와 SEC 원문 링크를 함께 표시합니다. Pershing은 13F-NT를 따라 2026년 실제 보고 주체 CIK 2026053을 사용합니다.
- 제공처 표 단위는 천 달러입니다. 금액 합계 검증 후 달러로 변환하고, 옵션·PRN을 제외한 주식수 기준 포지션을 CUSIP+종류로 합산합니다. 비중 분모도 이 보유액 합계입니다. 현금·공매도·비상장 등 전체 자산/AUM이 아닙니다.
- 최신 분기의 완전 신고 또는 정정본을 사용합니다. 추가 공시(NEW HOLDINGS)가 있으면 자동 합산을 보류합니다. 직전 연속 분기가 안전하게 비교될 때만 주식수 변화를 계산합니다. 분할·합병·식별 변경 때문에 실제 매매량과 다를 수 있습니다.
- 매주 토요일 08:00 KST와 Actions 수동 `gurus` 선택으로 확인합니다. 미국·아시아 자료와 비교 이력은 보존하며 수집 실패 기관은 이전 자료를 유지합니다. 초기 실패는 자료 없음으로 표시합니다.
- 별도 토큰·유료 API·브라우저 CORS 요청은 없습니다. 기관 4개, 순차 요청·400ms 간격, 요청당 15초, 작업 3분 제한입니다.
