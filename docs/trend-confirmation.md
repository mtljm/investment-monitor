# 상승 전환 확인표

사용자가 제공한 글의 핵심인 ‘과매도 반등과 추세 전환 구분, 변동성 관리, 일간 종가와 주간 추세 확인’을 시장 개요의 별도 확인표로 구현합니다. 글의 정규분포·V자 반등 빈도·2025년 4월 사례는 통계적 사실이나 예측 확률로 사용하지 않습니다.

S&P 500과 나스닥100을 각각 평가하며 조건 충족 수를 보여줍니다. 여섯 조건을 모두 만족할 때 ‘상승 근거 누적’이며, 상승 확률이나 매수 지시는 아닙니다.

| 확인 조건 | 자체 기준 |
| --- | --- |
| 바닥 유지 | 최근 5일 저가가 앞선 15일 최저가 이상, 5일 종가 범위 8% 이하 |
| 일봉 추세 회복 | 3일 연속 SMA20 위, SMA20이 5거래일 전 이상 |
| 거래량 동반 상승 유지 | 조정 후 반등 4일째 이후 +1.5% 이상·거래량 전일 초과 후보 발생, 후보 저가를 이후 3거래일 유지 |
| 대형주 확산 | 유효 상위 20개 표본 최소 15개, 그중 60% 이상이 SMA20 위이면서 5일 상승 |
| 주봉 확인 | 완료 주봉의 종가가 전주보다 높고 저가 유지, 4주 종가 평균 위 |
| 변동성 완화 | VIX 마감값 25 미만, 5일 전보다 하락 |

반등 탐색은 앞선 20일 최고 종가 대비 8% 이상 조정 또는 하루 −3% 이하 하락 후 시작합니다. 하락일 저가를 기준으로 첫 상승 종가를 1일째로 세고, 기준 저가 이탈 시 초기화합니다. 후보일 저가 이탈도 실패로 기록합니다. 3일째 강한 상승은 조기 후보로만 표시합니다. 최근 5거래일 내 실패는 상태에 우선 경고합니다.

기존 수집기는 일봉 high·low·volume을 차트 이력에 추가 저장하며 공개 JSON에서도 유지합니다. 최근 마감 거래일 이후의 장중 봉을 제외합니다. 완료 주봉은 미국 현지 날짜로 판단하고, 이력 첫 주는 부분 주일 수 있어 제외합니다. 금요일 휴장 주는 보수적으로 주말 이후 완료 처리합니다. 수집 지연·오류 시 판정을 보류합니다.

SPY·QQQ 거래량을 대용으로 사용합니다. 나스닥100은 나스닥종합과 다르며 공식 IBD FTD 판정이 아닙니다. 기준·기간은 자체 설계로 백테스트되지 않았습니다. 90개 일봉 이전의 반등·실패는 탐색하지 않으며 표본 대형주 확산은 전체 시장 폭이 아닙니다.

개념 참고: [Charles Schwab 추세 확인](https://www.schwab.com/learn/story/how-to-read-stock-charts-and-trading-patterns), [AAII의 후속 상승일 설명](https://www.aaii.com/journal/article/the-big-picture-how-to-determine-the-stock-market-s-direction). 이 자료의 특정 수치나 공식 신호를 그대로 재현하는 모델은 아닙니다.

검증: `node --test tests/trend-reversal.test.mjs`에서 조기 급등, 전일 거래량 미충족, 후보 저점 이탈, 유지 기간, 장중 제외, 완료 주봉, 자료 부족, 복합 충족 경로와 공개 데이터 보존을 검사합니다.
