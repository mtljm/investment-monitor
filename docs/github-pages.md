# GitHub Pages 운영

**접속 주소:** https://mtljm.github.io/investment-monitor/

- 공개 저장소 `main`에서 GitHub Actions로 생성한 시장 화면만 Pages에 게시합니다.
- 매일 한국시간 오전 7시 15분 목표로 대형주 20개와 지수·지표·ETF 23개를 수집합니다.
- 예약 실행은 지연·누락될 수 있습니다. 휴장일에는 최근 거래일 자료를 표시합니다.
- 휴대폰에서 주소를 열면 됩니다. 새로고침 자체는 수집 코드를 실행하지 않습니다.
- 수동 갱신: Actions → **Pages 시장 대시보드** → **Run workflow**.

표시 범위 20·50·100·200 메뉴는 유지합니다. 현재 배포에 없는 범위는 선택 불가하며, 해당 범위 JSON을 불러오면 사용할 수 있습니다.
기술적 분석 탭은 S&P 500·나스닥100·상위 20개만 다룹니다.

## 배포와 실패 처리

`.github/workflows/daily-pages.yml`은 변경 종류에 따라 수집 여부를 결정합니다.

| 실행 | 처리 |
| --- | --- |
| 매일 07:15 KST 예약 | 새 시세 수집 → 지표·비교 이력 계산 → 배포 |
| 수동 실행 기본값 | 새 시세 수집 후 배포 |
| 수동 실행에서 `refresh_data` 해제 | 게시 데이터를 재사용해 화면만 배포 |
| HTML·CSS·화면 JS 수정 | 게시 데이터를 재사용해 화면만 배포 |
| 수집 설정·지표 계산 코드 수정 | 새 시세 수집 후 배포 |

화면 배포는 Pages의 `latest.json`과 `history.json`을 읽습니다. 수집 시각·기술적 분석·전일 비교 신호·90일 이력은 유지하며, 비교 이력을 새로 계산하지 않습니다. 전환 첫 실행에서 `latest.json`이 없으면 기존 `index.html`의 내장 데이터를 사용합니다. 네트워크 오류나 데이터 버전 오류가 있으면 배포를 중단하며 자동으로 시세를 재수집하지 않습니다.

`latest.json`은 공개 시장 필드만 포함하는 버전 1 스냅샷입니다. 개인 계좌·보유량은 넣지 않습니다. 작업 전체를 같은 concurrency 그룹으로 직렬화해 화면 배포와 정기 수집의 충돌을 막습니다.

화면 소스는 `templates/dashboard.html`(구조), `dashboard.css`(스타일), `dashboard.js`(화면·공통 상세), `dashboard-safety.js`(갱신 상태·CSV), `market-temperature.js`(온도계), `sector-heatmap.js`(섹터 히트맵)로 나눕니다. `scripts/dashboard-template.mjs`가 배포 시 하나로 합치므로 다운로드한 HTML도 단독으로 열 수 있습니다.

수집에 실패하면 배포하지 않고 기존 사이트를 유지합니다. 화면의 수집 시각과 Actions 결과를 확인하세요.
결과를 Git에 자동 커밋하지 않으므로 저장소의 `reports/latest.json`과 실제 사이트 수집 시각은 다를 수 있습니다.

## 비용과 공개 범위

공개 저장소의 표준 Linux 실행기와 무료 GitHub Pages만 사용합니다.
유료 실행기·캐시·외부 서버·추가 토큰은 사용하지 않고, 실행 시간 제한과 아티팩트 보관 1일을 적용합니다.
기존 예산 차단 설정을 유지합니다.

사이트에는 시장 데이터만 게시하지만 **저장소 코드와 커밋 이력도 공개**입니다.
보유 수량·계좌번호·토큰은 커밋하지 마세요. 인증정보는 GitHub Secrets로 관리합니다.
배포 권한은 deploy 작업의 `pages: write`, `id-token: write`로 제한합니다.

## 갱신 상태 확인

- 화면 상단에서 수집 시각과 미국 주식의 최근 마감 거래일을 별도로 확인합니다.
- 매일 07:15 KST 이후 새 수집이 없으면 08:15까지 갱신 대기, 이후에는 자동 갱신 지연으로 표시합니다. 주말·휴장일에도 수집 배치는 매일 실행되는 설정입니다.
- 미국 주식·지수·ETF의 최신 봉은 뉴욕시간 17:00 이후 해당 거래일까지 기대하며, 주말과 NYSE의 2026–2028년 정기 휴장일을 제외합니다. 임시 휴장일은 달력 업데이트가 필요합니다. 지원 연도 밖은 판단 불가로 표시합니다.
- 금리·환율·VIX는 서로 다른 거래 일정을 가지므로 4일 경과 경고를 유지합니다.
- 화면을 계속 열어 두어도 경고는 1분마다 다시 판단합니다. 시세 자체를 재수집하지는 않습니다.
- 지연 경고가 보이면 Actions의 마지막 실행 결과를 확인하고 필요하면 수동 갱신합니다.
- CSV의 음수 수익률은 숫자로 저장합니다. 텍스트의 수식 시작 문자만 보호하며 쉼표·따옴표·줄바꿈은 CSV 규칙으로 처리합니다.
