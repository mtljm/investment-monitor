# 52주 고점 대비

`(최근 유효 일봉 종가 / 해당 기간 장중 고가 최댓값 - 1) × 100`으로 계산합니다.
기간은 최근 유효 일봉의 날짜를 포함한 364개 달력일(52주)입니다. 252거래일로 대체하지 않아 비트코인에도 같은 달력 기간을 적용합니다.
동일 고점이 여러 번 나오면 가장 최근 날짜를 표시합니다.

52주 전체를 덮는 이력이 없거나 기간 내 고가가 누락·이상값이면 —로 표시합니다. 최근 90봉만으로 계산하지 않으며, 기존 2년 수집 자료를 사용합니다.
최근 일봉이 장중이면 값이 바뀔 수 있습니다. 원본 OHLC 기준이며 배당 재투자를 반영한 총수익률이나 MDD가 아닙니다. 가격 제공처의 분할 처리·기간 정의에 따라 다른 서비스와 차이가 날 수 있습니다.

지수 카드와 두 종목 표의 현재가 아래에 표시하고, 상세 창에서 고점 가격·날짜를 확인합니다. 표의 ‘52주 대비’ 버튼으로 정렬할 수 있습니다. 추가 API 호출은 없습니다.
