# investment-monitor

내 투자 포트폴리오와 시장 상황을 함께 점검하고, 투자 판단의 근거와 결과를 기록하는 개인 투자 관리 저장소입니다.

## 목적

**기술적 분석을 활용하고, 위험을 점검하며 안정적인 포트폴리오 운용을 지향합니다.**
안정성의 구체적인 기준(허용 손실, 종목 집중도, 현금 비중 등)은 추후 정합니다.

- 보유 자산의 구성, 평가금액, 손익과 비중을 파악합니다.
- 주요 시장 지표와 뉴스가 내 포트폴리오에 미치는 영향을 점검합니다.
- 매수·보유·매도 판단의 근거를 기록하고 이후 결과를 돌아봅니다.
- 데이터를 먼저 정리하고, 필요한 분석과 자동화를 단계적으로 추가합니다.

## 투자 및 모니터링 범위

- **투자 대상:** 미국 대형주와 미국 주식 지수 ETF
- **분석 방향:** 장기 지수 투자와 단기 기술적 매매를 구분하여 점검
- **운용 점검:** 종목·업종 집중도, ETF 간 편입 종목 중복, 현금 비중과 손실 위험 확인
- **시황 점검:** 주요 시장지표를 소수로 추려 간단히 모니터링

관찰 대형주는 출처의 미국 기업 시가총액 상위 200개로 구성하며, 화면에서 20·50·100·200개를 선택합니다.
실제 투자 대상 ETF와 운용 비중은 추후 확정합니다.
분석 지표와 세부 운용 기준은 추후 정합니다.

## 포트폴리오 운용 구조

투자금의 약 80%는 지수 ETF를 이용한 장기 포트폴리오로, 나머지 약 20%는 단기 기술적 매매로 운용합니다.

| 구분 | 목표 비중 | 목적 | 주요 점검 사항 |
| --- | --- | --- | --- |
| 장기 포트폴리오 | 약 80% | 지수 ETF를 활용한 장기 자산 운용 | 지수·ETF 구성, 자산 배분, 편입 종목 중복, 비중 변화 |
| 단기 매매 | 약 20% | 기술적 매매를 통한 초과수익 추구 | 가격 추세, 거래량, 진입·청산 근거, 손실 관리, 거래 비용 |

- 보유 자산과 거래 기록에 장기·단기 구분을 남깁니다.
- 전체 포트폴리오와 장기·단기 부문의 성과를 각각 기록합니다.
- 80:20은 대략적인 목표 배분입니다. 비중 산정 기준, 허용 편차와 리밸런싱 조건은 추후 확정합니다.
- 초과수익의 비교 기준, 단기 매매의 보유 기간·손실 한도·진입 및 청산 규칙도 추후 정합니다.

## 점검할 내용

### 투자 포트폴리오

| 항목 | 기록 내용 |
| --- | --- |
| 보유 현황 | 장기·단기 구분, 자산명, 종목코드, 자산군, 통화, 보유수량, 평균매입단가 |
| 평가 현황 | 기준일, 가격, 환율, 원화 환산 평가금액, 평가손익 |
| 자산 배분 | 종목별·자산군별·통화별 비중과 현금 비중 |
| 기술적 분석 | 추세, 거래량, 변동성 및 추후 선정할 기술적 지표 | 
| 운용 위험 | 종목·업종 집중도, ETF 간 편입 종목 중복, 손실 위험 |
| 투자 근거 | 투자 목적, 기대 요인, 주요 위험, 재검토 조건 |
| 거래 및 현금흐름 | 매매, 입출금, 배당·분배금, 수수료·세금 |

수익률을 계산할 때는 환율, 입출금, 배당, 수수료·세금의 반영 여부를 명시합니다.
실제 보유 자산과 부문별 세부 비중은 보유 현황을 정리한 뒤 확정합니다.

### 시황

미국 대형주와 지수 ETF의 운용에 필요한 시장 배경을 짧게 정리합니다.

- 주요 미국 주가지수, 미국 금리, 시장 변동성, 원/달러 환율을 중심으로 소수 지표 선정
- 주요 경제지표 발표와 연방준비제도 정책 일정 요약
- 보유 자산에 직접 관련된 중요 뉴스·공시와 영향 요약

세부 지표와 데이터 출처는 추후 선정하며, 시황 보고서는 핵심 변화 위주로 간결하게 유지합니다.

관찰한 사실, 해석, 실행할 행동을 구분해 기록합니다.
뉴스와 지표에는 출처 링크와 기준 시점을 남깁니다.

## 점검 기록 형식

각 점검은 다음 순서로 정리합니다.

1. **기준 시점** — 평가 기준일, 가격·환율의 관측 시각
2. **포트폴리오 현황** — 평가금액, 비중, 손익, 이전 점검 대비 변화
3. **시장 상황** — 주요 지표와 사건, 출처
4. **내 자산에 미치는 영향** — 관련 자산, 기회와 위험, 판단 근거
5. **후속 조치** — 추가 조사, 관찰 조건, 다음 점검 사항

확인하지 못한 값은 추정값으로 채우지 않고 미확인으로 표시합니다.
해외 자산은 현지 통화와 원화 환산 값을 구분합니다.

## 시장 모니터링 시작

보유 자산 입력에 앞서 시장 모니터링부터 구현했습니다.

- [HTML 대시보드](dashboard.html) — 파일을 내려받아 브라우저로 열기
- [최신 실행 보고서](reports/latest.md)
- [실행 방법과 지표 정의](docs/market-monitoring.md)
- [관찰 대상 목록](config/monitor.json)

Node.js 22 이상에서 `node scripts/monitor.mjs`로 수동 실행합니다.
실행 시 `dashboard.html`과 `reports/latest.json`도 함께 갱신됩니다.
HTML은 데이터를 포함한 단일 파일이어서 별도 서버 없이 열 수 있습니다. GitHub 파일 화면은 소스 보기이므로 파일을 내려받아 여세요.
지수 4개, 주요 지표 3개, 지수 ETF 4개, 미국 섹터 ETF 11개와 대형주 최대 200개(총 222개)를 수집합니다.
시장 개요에 섹터별 요약이 있으며 관찰 종목의 ‘섹터 ETF’ 탭에서 상세 지표를 확인합니다.
왼쪽의 시장 개요·관찰 종목·데이터 상태는 탭이며 선택한 화면만 표시합니다.
순위 목록 갱신: `node scripts/update-universe.mjs`
수집 범위 지정 예시: `node scripts/monitor.mjs --limit 50` (20·50·100·200 지원)

## 데이터 관리

- 계좌번호, 로그인 정보, 비밀번호, API 키는 저장소에 기록하지 않습니다.
- 증권사 원본 자료와 상세 거래 내역은 필요한 항목만 정리하여 사용합니다.
- 외부 서비스 연동 시 인증 정보는 코드와 분리하고 Git 추적에서 제외합니다.
- 실시간 값과 지연·종가 데이터를 구분하고, 수집 시점과 출처를 함께 기록합니다.
