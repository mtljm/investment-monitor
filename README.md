# investment-monitor

안정적인 포트폴리오 운용을 위해 미국 시장을 기술적으로 분석하고 투자 판단을 기록하는 개인 모니터입니다.
운용 방향은 **장기 지수 투자 약 80% + 단기 기술적 매매 약 20%**입니다.

## 현재 기능

- 미국 대형주 상위 **20·50·100·200개** 선택
- 지수 4개, 주요 지표 4개, 지수 ETF 4개, 섹터 ETF 11개 조회
- 시장 개요·관찰 종목·데이터 상태 탭, 검색·정렬·CSV 저장
- 종목 세부 화면에서 MA·RSI·MACD·볼린저 밴드와 설명 확인
- 기술적 분석 탭: S&P 500(SPX)·나스닥100·상위 20개 주식의 추세·RSI·볼린저·OBV·피보나치 구간과 종합 해석
- **매일 한국시간 오전 7시 37분 목표**로 GitHub Pages 시장 화면 갱신

배포는 상위 20개 데이터를 포함하며, 50·100·200 선택 메뉴는 해당 범위 JSON을 불러올 때 사용할 수 있습니다.
Pages 정기 실행은 대형주 20개를 포함한 **43개 항목**입니다.
GitHub 예약 실행은 지연·누락될 수 있으며, 휴장일에는 최근 거래일 자료를 사용합니다.
보유 자산·계좌 연동과 자동 매매는 아직 구현하지 않았습니다.

## 사용하기

휴대폰 또는 PC에서 **[시장 대시보드 열기](https://mtljm.github.io/investment-monitor/)** 를 누르세요.
설치·압축 해제·로그인이 필요 없습니다. 화면의 수집 시각을 확인하세요.
수동 갱신은 GitHub Actions의 **01 시장 · 예약 및 화면 갱신 → Run workflow**에서 실행합니다.

Node.js 22 이상에서 직접 실행할 수도 있습니다.

```sh
node scripts/monitor.mjs --limit 20  # 20·50·100·200 지원
node scripts/update-universe.mjs    # 대형주 순위 갱신
node scripts/render-dashboard.mjs  # 기존 JSON으로 HTML 재생성
```

페이지 새로고침은 시세를 수집하지 않습니다. 수집 스크립트를 실행하거나 새 JSON을 불러오세요.

화면 소스(HTML·CSS·화면 JS) 수정은 기존 게시 데이터를 재사용해 배포합니다. 미국·아시아 정기 배치는 각각 해당 시장만 수집합니다. 화면 배포 수동 실행은 기본 `reuse`이며, `us / asia / gurus / all`을 선택하면 지정한 시장을 수집합니다. 자세한 구조는 [Pages 운영](docs/github-pages.md)을 참고하세요.

## 아시아 지수

아시아 지수 탭은 KOSPI·KOSDAQ·닛케이225·항셍·상하이종합·대만가권을 별도로 표시합니다. 미국장 통계는 변경하지 않습니다. `node scripts/collect-asia.mjs`로 수집하며 `reports/asia-latest.json`에 기록합니다. 아시아 전용 배치가 지수를 수집하고 기존 미국장 스냅샷을 보존해 게시합니다. 일부 실패는 해당 카드에 표시하며 미국장 배포를 중단하지 않습니다. 각 시장 시세·거래일을 확인하세요. 장중 자료는 바뀔 수 있고 실시간 스트리밍·지역별 휴장일 정밀 판정은 아직 지원하지 않습니다.

## 시장별 배치

- 01 시장 · 예약 및 화면 갱신 (us): `daily-pages.yml`, 매일 07:37 KST (`37 22 * * *`). 미국만 수집하고 게시된 아시아 자료는 유지합니다.
- 01 시장 · 예약 및 화면 갱신 (asia): `daily-pages.yml`, 평일 17:30 KST (`30 8 * * 1-5`). 아시아만 수집하고 미국 자료·수집 시각·비교 이력은 유지합니다. 각 시장 휴장일에는 최근 자료일 수 있습니다.
- 01 시장 · 예약 및 화면 갱신: `daily-pages.yml`에서 `us / asia / gurus / all / reuse`를 선택합니다. 기본 `reuse`는 시세 수집 없이 화면만 게시합니다. 기존 `refresh_data` 체크박스는 시장 선택으로 대체했습니다.
- 공통 게시 `publish-market.yml`의 단일 잠금으로 수집·최신 스냅샷 읽기·배포·공개 데이터 확인을 직렬화합니다. 실행 중 작업은 취소하지 않습니다. GitHub concurrency 특성상 대기 실행이 여러 개 쌓이면 이전 대기 실행이 대체될 수 있습니다.
- 시각 변경 시 `config/batch-schedules.json`과 통합 워크플로의 cron을 함께 수정합니다. 테스트가 두 설정의 일치를 검사합니다. GitHub 예약 실행은 지연·누락될 수 있으며 분리만으로 기존 예약 미생성 문제가 해결됐다고 볼 수는 없습니다.

관찰종목 대형주에는 시가총액 상위 선택 범위와 함께 버크셔 해서웨이 B(BRK-B)를 직접 추가합니다. config/monitor.json의 watchlist_additions를 사용하며 순위 목록을 갱신해도 유지됩니다.

시장 개요의 상승 전환 확인표는 바닥 유지·일봉 회복·거래량 동반 상승 유지·대형주 확산·완료 주봉·VIX 완화를 구분합니다. 자체 조건과 한계는 [상승 전환 확인표](docs/trend-confirmation.md)를 참고하세요.

시장 폭과 주도주: NYSE·Nasdaq 전체 상승/하락 거래량 10:1과 반복 여부, 상위 200개+버크셔의 자체 주도주 후보·증감·진입/이탈을 별도 표시합니다. 자세한 대상·계산·누락 처리는 [시장 폭과 주도주](docs/market-participation.md)를 참고하세요.
