# investment-monitor

내 투자 포트폴리오와 시장 상황을 함께 점검하고, 투자 판단의 근거와 결과를 기록하는 개인 투자 관리 저장소입니다.

## 목적

- 보유 자산의 구성, 평가금액, 손익과 비중을 파악합니다.
- 주요 시장 지표와 뉴스가 내 포트폴리오에 미치는 영향을 점검합니다.
- 매수·보유·매도 판단의 근거를 기록하고 이후 결과를 돌아봅니다.
- 데이터를 먼저 정리하고, 필요한 분석과 자동화를 단계적으로 추가합니다.

## 점검할 내용

### 투자 포트폴리오

| 항목 | 기록 내용 |
| --- | --- |
| 보유 현황 | 자산명, 종목코드, 자산군, 통화, 보유수량, 평균매입단가 |
| 평가 현황 | 기준일, 가격, 환율, 원화 환산 평가금액, 평가손익 |
| 자산 배분 | 종목별·자산군별·통화별 비중과 현금 비중 |
| 투자 근거 | 투자 목적, 기대 요인, 주요 위험, 재검토 조건 |
| 거래 및 현금흐름 | 매매, 입출금, 배당·분배금, 수수료·세금 |

수익률을 계산할 때는 환율, 입출금, 배당, 수수료·세금의 반영 여부를 명시합니다.
보유 자산과 목표 비중은 실제 정보를 정리한 뒤 확정합니다.

### 시황

- 주요 주가지수, 금리, 환율 및 필요에 따른 원자재 지표
- 경제지표 발표, 중앙은행 정책 및 주요 시장 일정
- 보유 종목·업종과 관련된 뉴스와 공시
- 시장 변화가 보유 자산에 미칠 영향과 추가 확인 사항

관찰한 사실, 해석, 실행할 행동을 구분해 기록합니다.
뉴스와 지표에는 출처 링크와 기준 시점을 남깁니다.

## 점검 기록 형식

각 점검은 다음 순서로 정리합니다.

1. **기준 시점** — 평가 기준일, 가격·환율의 관측 시각
2. **포트폴리오 현황** — 평가금액, 비중, 손익, 이전 점검 대비 변화
3. **시장 상황** — 주요 지표와 사건, 출처
4. **내 자산에 미치는 영향** — 관련 자산, 기회와 위험, 판단 근거
5. **후속 조치** — 추가 조사, 관찰 조건, 다음 점검 사항

확인하지 못한 값은 추정값으로 채우지 않고 미확인으로 표시합니다.
해외 자산은 현지 통화와 원화 환산 값을 구분합니다.

점검 주기와 자동화 범위는 사용하면서 정합니다.

## 향후 폴더 구성안

아래는 예정된 구조이며, 필요한 단계에서 폴더와 파일을 추가합니다.

```text
investment-monitor/
├── README.md
├── docs/         # 투자 원칙, 지표 정의, 데이터 출처
├── portfolio/    # 보유 현황과 자산 배분 기록
├── reports/      # 날짜별 포트폴리오·시황 점검
└── scripts/      # 추후 데이터 수집·분석 도구
```

## 데이터 관리

- 계좌번호, 로그인 정보, 비밀번호, API 키는 저장소에 기록하지 않습니다.
- 증권사 원본 자료와 상세 거래 내역은 필요한 항목만 정리하여 사용합니다.
- 외부 서비스 연동 시 인증 정보는 코드와 분리하고 Git 추적에서 제외합니다.
- 실시간 값과 지연·종가 데이터를 구분하고, 수집 시점과 출처를 함께 기록합니다.
